🤖 New: Pricing Agent

backend/app/agents/pricing_agent.py — Calculates operating cost and demand-adjusted pricing

Architecture principle: The Route Agent decides which route. The Pricing Agent decides how much it costs. Each agent has a single responsibility.
📄 NEW — backend/app/agents/pricing_agent.py
import os import pandas as pd class PricingAgent: def __init__(self): # Load pricing.csv from app/data/ current_file = os.path.abspath(__file__) project_root = os.path.dirname(os.path.dirname(os.path.dirname(current_file))) self.pricing_path = os.path.join(project_root, "app", "data", "pricing.csv") self.pricing = pd.read_csv(self.pricing_path) def calculate_pricing(self, route_id, base_freight): # Find pricing data for the given route pricing_data = self.pricing[self.pricing["route_id"] == route_id] if pricing_data.empty: return {"status": "not_found", ...} pricing = pricing_data.iloc[0] # Extract surcharges fuel_surcharge = float(pricing["fuel_surcharge_usd"]) port_charge = float(pricing["port_charge_usd"]) risk_surcharge = float(pricing["risk_surcharge_usd"]) demand_factor = float(pricing["demand_factor"]) # Calculate costs operating_cost = base_freight + fuel + port + risk demand_adjusted_cost = operating_cost × demand_factor return { "status": "success", "operating_cost_usd": operating_cost, "demand_adjusted_cost_usd": demand_adjusted_cost, # ... full breakdown included }

📄 New: Quotation Service

backend/app/services/quotation_service.py — Orchestrates Route Agent + Pricing Agent

Key concept: The Quotation Service doesn't contain any decision logic itself. It coordinates the Route Agent and Pricing Agent, then assembles the final quotation.
📄 NEW — backend/app/services/quotation_service.py
class QuotationService: def __init__(self): self.route_agent = RouteAgent() self.pricing_agent = PricingAgent() def generate_quotation(self, origin, destination, cargo_type, containers): # Step 1: Ask Route Agent for best route route_result = self.route_agent.analyze_route(origin, destination, ...) # Step 2: Extract the best route best_route = [r for r in route_result["routes"] if r["is_best"]][0] # Step 3: Get pricing from Pricing Agent pricing = self.pricing_agent.calculate_pricing(best_route["route_id"], base) # Step 4: Calculate freight freight_per_container = pricing["demand_adjusted_cost_usd"] total_freight = freight_per_container × containers # Step 5: Build alternative quotations # Step 6: Return complete quotation return { "status": "success", ... }

🧮 Scoring Weights

FactorWeightLogic
🕐 Transit Time40%Faster → Higher score
💰 Cost30%Cheaper → Higher score
🔄 Transshipments30%Fewer → Higher score
# Score formula Score = 100 - ( transit_norm × 40 + cost_norm × 30 + transship_penalty × 30 )
